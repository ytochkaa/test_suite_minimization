# test_suite_minimization (C++17)

Компонент читает JSON версии 1, строит покрытие исходных требований и доступных границ, затем выбирает поднабор тестов.

Поддерживаются простые целочисленные CHECK с `<`, `<=`, `>` и `>=`:

- `column op constant`;
- `column op column`.

Для ненулевых операндов учитываются расстояния −1, 0 и +1. NULL записывается отдельными категориями `left-null`, `right-null`, `both-null`. Разность вычисляется в `__int128`, поэтому вычитание значений `BIGINT` не переполняется.

Алгоритм сначала сохраняет единственных свидетелей требований, затем выполняет детерминированный жадный выбор. При равенстве выигрывает тест с меньшим числом вставок, затем с меньшим идентификатором. После выбора выполняется обратное удаление избыточных тестов и независимый пересчёт объединения покрытия.

Сборка:

```text
cmake -S cpp -B build/cpp -G Ninja
cmake --build build/cpp
```

Запуск:

```text
build/cpp/test_suite_minimization input.json report.json
```

Каталог `build/` и отчёты экспериментов не добавляются в Git.
