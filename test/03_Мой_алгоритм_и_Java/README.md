# 3. Собственный алгоритм и Java-обвязка

В `java/` помещены Java-классы, которые сохраняют набор, экспортируют его в JSON и передают между этапами. Они не заменяют генератор SchemaAnalyst.

В `cpp/` находятся исходники собственного алгоритма `boundaryAware`, описание сборки и `tests/test_minimizer.cpp`. Алгоритм получает JSON с тестами, сведениями о покрываемых требованиях и PostgreSQL-подтверждениями. Он выбирает целые `TestCase`, стремясь сохранить требования и подтверждённые граничные наблюдения.

Это копии исходников для удобства чтения. Рабочие версии находятся в `test_suite_minimization/src/main/java/org/schemaanalyst/minimization` и `test_suite_minimization/cpp`; сборку выполняйте из корня проекта по командам в `docs/BUILD_AND_TESTS.md`.
