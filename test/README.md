# Демонстрационные материалы эксперимента

Эта папка собирает в одном месте реальные файлы одного эксперимента, чтобы было наглядно видно, какие данные получает каждый этап и что он выдаёт. Это пример для `avsDefaults`, seed `0`, критерия `CondAICC` и бюджета `10000`, а не полная матрица экспериментов.

## Папки по порядку выполнения

1. [`01_Описание_схемы_критерий_генератор`](./01_Описание_схемы_критерий_генератор/README.md) — Java-описание схемы, PostgreSQL DDL и параметры генерации.
2. [`02_Набор_тестов_SchemaAnalyst`](./02_Набор_тестов_SchemaAnalyst/README.md) — исходный снимок SchemaAnalyst, его JSON-экспорт и фактическая проверка полного набора в PostgreSQL.
3. [`03_Мой_алгоритм_и_Java`](./03_Мой_алгоритм_и_Java/README.md) — Java-обвязка обмена данными, C++-алгоритм `boundaryAware` и его тесты.
4. [`04_Результаты_двух_подходов`](./04_Результаты_двух_подходов/README.md) — контрольный исходный набор, результат штатного `simpleGreedy` SchemaAnalyst и результат `boundaryAware`, а также таблица сравнения.

## Как читать результаты

- `00_Исходный_набор` — контрольный запуск `none`, то есть исходный набор без сокращения.
- `01_SchemaAnalyst_simpleGreedy` — результат одного штатного алгоритма сокращения SchemaAnalyst.
- `02_boundaryAware` — результат собственного C++-алгоритма сокращения тестового набора.

Оба алгоритма получили один и тот же исходный снимок; SHA-256 указан в `comparison.csv`. JSON-файлы `*-validated.json` содержат факты выполнения тестов в PostgreSQL. CSV-файлы содержат результат по каждому `TestCase`. Сводные количества, время, покрытие и статусы находятся в `comparison.csv`.

Файлы здесь скопированы для наглядной демонстрации. Основные исходники и полный комплект эксперимента остаются в каталогах `test_suite_minimization/src`, `test_suite_minimization/cpp` и `test_suite_minimization/experiments`.
