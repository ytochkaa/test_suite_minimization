# 2. Исходный набор SchemaAnalyst

Здесь лежит результат генерации до сокращения:

- `source/avsDefaults-0.ser` — сериализованный Java-снимок схемы, требований и `TestSuite`. Это исходный неизменяемый вход для сравнительных запусков.
- `input/avsDefaults-0-full.json` — читаемый экспорт тестов, SQL-вставок и требований.
- `input/avsDefaults-0-full-validated.json` — тот же полный набор после выполнения в PostgreSQL; содержит фактические результаты.
- `postgres/avsDefaults-0-full-postgres.csv` — результат проверки PostgreSQL: строки соответствуют отдельным тестовым случаям.

Поля каждого `TestCase` разделены по назначению: `state` подготавливает нужное состояние базы, `data` содержит проверяемые строки. Значения и SQL извлечены из одного снимка; JSON не является новым независимым набором тестов.
