# 1. Описание схемы, критерий и генератор

На этом этапе задаётся, **какие данные и проверки** будут основой эксперимента.

- `java/CourseworkSchema.java` — схема, которую SchemaAnalyst использует при построении требований и генерации тестов.
- `schema.sql` — соответствующее описание таблиц и ограничений для PostgreSQL, где будут исполняться тестовые вставки.
- `java/GenerateBaselineSnapshot.java` — Java-обвязка: задаёт `CondAICC`, создаёт требования, запускает указанный генератор и сохраняет полученный набор.
- `experiment-parameters.json` — параметры именно того запуска, артефакты которого разложены в соседних папках.

В этом примере используются критерий `CondAICC`, генератор `avsDefaults`, seed `0` и бюджет `10000`. При запуске SchemaAnalyst использует Java-описание схемы; файл SQL нужен PostgreSQL-валидатору, а не для передачи в C++-алгоритм.
