# 4. Результаты двух подходов

В этой папке сведены результаты одного и того же исходного набора:

- `00_Исходный_набор` — контроль `none`, то есть все исходные тесты без сокращения.
- `01_SchemaAnalyst_simpleGreedy` — пример результата штатного алгоритма `simpleGreedy` SchemaAnalyst.
- `02_boundaryAware` — результат собственного алгоритма `boundaryAware`.
- `comparison.csv` — сравнение числа тестов и INSERT, времени, требований, границ и результатов PostgreSQL.

В каждой папке метода находится JSON выбранного набора, `*-validated.json` с фактическими результатами PostgreSQL, отчёт покрытия и CSV выполнения тестов. Для `boundaryAware` также приложен полный отчёт выбора.

Это один реальный запуск (`avsDefaults`, seed `0`), а не результат всей матрицы. В нём и `simpleGreedy`, и `boundaryAware` оставили по 48 из 54 тестов; сохранили 54/54 требования и 5/5 подтверждённых границ; PostgreSQL подтвердил 48/48 результатов для каждого. Время алгоритмов и остальные поля смотрите в `comparison.csv`. Полная матрица с четырьмя генераторами описана в `docs/RESULTS_BASELINE.md`.
